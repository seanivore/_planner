# Rectangle of Happiness — Block Spec v3

## Form Factor
- 8 × 7 × 3 in. Magnesium/titanium shell. Ribbed, Rimowa-style. Clutch/satchel ready. No exposed glass.
- Pen + pad (Wacom-class, replaceable surface, pressure/tilt/hover).
- AR glasses (2–3K/eye, UWB, prescription-ready, minimal HUD).
- Bone conduction earpiece.
- Desk typing: vision/acoustic finger tracking, IR key outline option.
- Minimal capacitive/tactile edge controls. No moving parts. Vapor chamber cooling, fanless.

## Sensors & Cameras
- Stereo RGB/IR front cameras (face, hand, object, desk).
- LIDAR array (depth, gesture, room mapping, AR overlays).
- IMU, ambient/thermal, ultrasonic mic for tap/gesture.
- Privacy: hardware shutter, visible sensor indicator.

## Ports
- 5 USB-C (power, display, storage, expansion).
- Full-size HDMI (no dongle).
- 3.5mm audio jack.
- SD card slot (removable, legacy).
- Pogo connector (hot-swap battery sleeve).
- All user-accessible. Standard tool opens panels. No glue. No “void warranty” stickers.

## Compute
- NPU-first ARM SoC, 64GB RAM minimum (128GB optional).
- 1TB NVMe SSD standard, user-upgradeable (2TB+ optional).
- Wi-Fi 7, BT 5.4, LTE/5G eSIM, UWB.
- Modular comms: pop-out/slide-in radio module for future edge/mesh/6G.

## OS
- AI-native, project-based. No app silos.
- Modular, upgradeable: RAM, SSD, battery, comms module.
- Local agent framework, offline-first, privacy-by-design.
- Context graph: files, notes, contacts, gestures, all linked.
- Open API for custom flows/tools.
- Software updates: user-initiated, rollback supported.

## Accessories
- Rimowa-vibe clutch bag, modular battery sleeve.
- Glasses (minimal HUD, prescription-ready).
- Watch (haptics, EMG micro-gestures).
- Earpiece (bone conduction, interpreter mode).
- Portable 4K monitor (USB-C, sub-$300).

## Interaction
- Pen-first canvas, desk typing (vision/acoustic), gesture/voice.
- Glasses: HUD overlays, timeline, prompts.
- Earpiece: dictation, phone, whisper commands.
- “Theremin mode” for music/scrubbing.

## Durability & Upgrades
- IP54+, magnesium/metal frame, replaceable panels.
- All user-upgradeable: RAM, SSD, battery, comms module.
- No glass to shatter; replaceable pad surface.
- No glue. No soldered RAM. No pentalobe screws.
- Panels: tool-open, child-proof, indestructible in a fall.

## Modularity
- Upgrade SSD, RAM, battery, comms without being “tech savvy.” Remove 2 screws, slide out, pop in new.
- Indestructible by default. Panels require tool, not fingernails. Still passes drop test.

## Sensor Suite
- LIDAR for AR overlays, precise finger/hand/desk detection, “keyboardless” typing.
- Stereo RGB/IR for face, object, and room recognition.
- Ultrasonic for tap/gesture confirmation.
- All sensors upgradable via modular slot; future-proof for new input paradigms.

## MVP Roadmap (12mo)
- 0–2mo: desk typing + pen pad prototype.
- 3–4mo: OS alpha, agent flows, context graph.
- 5–6mo: hardware EVT, battery sleeve, thermal tests.
- 7–9mo: AR glasses, earpiece, UWB pairing.
- 10–12mo: beta kits, public case studies (whiteboard, street-to-studio, music edit).

## Why Now
- Apple won’t do it. OpenAI/Anthropic could.
- Creatives, generalists, and pattern-driven users need a real OS, not a “rectangle of sadness.”
- Modularity = longevity, no forced obsolescence.
- Ports for people who build. No dongle life. No glue. No sadness rectangles.
